## 0. 一句话定位

本地生活「吃什么」推荐产品。**商户每天只能发布 1 道新菜**（图文或视频二选一），用户在客户端以抖音式全屏滑卡刷「附近今天的新菜」。**不做交易闭环**，到店靠导航 / 电话 / 跳第三方。

**三个关键算法**（必须照抄，是业务核心）：

```js
// ① 价格自动归档：商家只填价格，档位由平台区间决定
getTierByPrice(price) {
  const p = Number(price);
  if (isNaN(p) || p < 0) return null;
  for (const t of this.priceTiers) if (p >= t.min && p < t.max) return t;
  return this.priceTiers[this.priceTiers.length - 1];
},

// ② 时间衰减：24h 内线性衰减，之后归零（但不物理删除）
timeDecay(publishedAt) {
  const t = new Date(publishedAt.replace(/-/g, '/')).getTime();
  const hours = (Date.now() - t) / 3600000;
  if (hours >= 24) return 0;
  return 1 - hours / 24;
},

// ③ 出流：筛选 + 每店一条 + 排序，全部收敛在这一个方法里。
//    页面只负责渲染 —— 这是保证「筛选页与首页口径一致」的关键。
matchFilter(d, f) {
  if (!d) return false;
  const x = f || this.getFilter();
  if (!this.filterActive(x)) return true;
  const tierOk  = !x.tiers.length  || x.tiers.includes(d.priceTierId);
  const tasteOk = !x.tastes.length || (d.tasteTags || []).some(t => x.tastes.includes(t));
  return tierOk && tasteOk;            // 维度内 OR，维度间 AND
},

buildFeed(tab, filter) {
  const f = filter || this.getFilter();
  const active = this.filterActive(f);

  let pool = this.dishes.filter(d => d.status === 'normal');
  if (active) pool = pool.filter(d => this.matchFilter(d, f));

  // 每店一条：取发布时间最新的那条（筛选态下即"符合条件的最新一条"）
  const byShop = {};
  pool.forEach(d => {
    const cur = byShop[d.shopId];
    if (!cur || this._ts(d.publishedAt) > this._ts(cur.publishedAt)) byShop[d.shopId] = d;
  });
  let items = Object.values(byShop);

  // 内容不足回退（决策 D2）—— 只在未筛选时；筛选态回退会让筛选失效
  if (!active && items.length < 3) { /* 从全量里补"未出现过的店"，见 mock.js */ }

  if (tab === 'random') return 打乱(items);
  return items.sort(/* 置顶 > 权重 > 距离 > 时间衰减 */);
}
```

**筛选条件持久化**：存 `localStorage`，key `clientFilter`，结构
`{ tiers: ['tier_mid'], tastes: ['麻辣'] }`。空数组表示该维度不限；
两维都空则直接删除 key（不留脏状态）。筛选页勾选**实时写入**，
首页出流时读取 —— 这是"筛选完首页跟着变"的全部机制。
`_ts(v)` 是内部时间解析工具，同时兼容 `'yyyy-MM-dd HH:mm'` 字符串与毫秒时间戳。

**排序优先级**：置顶 > 权重 > 距离 > 时间衰减。

## 5. 业务规则（不可违背，用户已逐条冻结）

1. **每店每天默认只能发 1 条**；平台端可覆盖为 `间隔小时 + 日上限`。
2. **规则变更不影响已发记录，从下次算起。**
3. 内容形式 **图文（1-9 图）/ 视频（≤15s ≤20MB）二选一，发布后不可改类型**。
4. **必填**：菜名、店名。**选填**：简介（≤100 字）、价格、视频封面。
5. **店铺审核，菜品不审核**；但菜品要打**真实性标签**（实拍认证 / 广告）并对**价格**做区分。
6. **内容永久不物理删除**。首页靠**时间衰减降权**自然沉底；店铺页永久保留全部菜品。
7. 价位分 **中等 / 高等 / 超高级** 三档，由平台区间自动归档，**商家不可手选**。
8. 筛选维度只有 **价格档 / 口味 / 距离**（距离本期固定"不限"）。**不做搜索**，靠纯随机。
   - 逻辑：维度内 **OR**（多选口味命中任一即可），维度间 **AND**（价格档与口味都要满足）
   - **筛选条件作用于首页信息流**，不只是筛选页：条件存 `localStorage`，
     筛选页勾选**实时同步**，首页顶部出现条件条，可一键清除
   - 筛选态下每店取「符合条件的**最新一条**」（不是笼统的最新一条），**不限 24h**，
     且**禁用**「不足 3 条回退旧内容」—— 回退会把不符合条件的菜塞回来，筛选就失效了
   - 筛选后仍守「每店一条」，与首页既有结构一致
   - **失效条件自动收敛**：平台删掉价格档后用户浏览器里遗留的旧 id 会被自动剔除
     （`sanitizeFilter`，只减不增；数据源为空时跳过校验，避免误清空用户条件）
9. 互动只做 **点赞 / 收藏 / 评论**；分享、导航、电话、跳第三方收进「更多」三级菜单。
10. **打卡用滑动解锁**（不是点赞按钮）——滑动的沉浸感更强。
11. **不做订单 / 交易**。身份是"推荐"，不是"外卖"。
12. 违规处理三级：**内容下架 → 商家禁言 → 封店**；用户侧：**警告 → 限评论 → 封号**，封号保留历史评论。
13. 排序按**地区**处理（本地生活优先）。
14. 推荐排名支持：**拖拽排序、置顶、权重**，且有客户端实时预览。

## 6. 关键交互实现要点

| 功能 | 实现方式 |
|---|---|
| 全屏竖向滑卡（feed） | CSS `scroll-snap-type: y mandatory` + `scroll-snap-align: start` |
| 横向图片轮播（dish） | CSS `scroll-snap-type: x mandatory` + 圆点指示器 + `1/3` 计数 |
| 记录已浏览（随心看排除） | `IntersectionObserver`，`threshold: 0.6`，写入 `S.browsed` |
| 排名拖拽排序 | HTML5 原生拖拽 `dragstart` / `dragover` / `drop` |
| 滑动打卡 | 指针事件 `mousedown`/`touchstart`/`mousemove` 拖 `slide-thumb` 解锁 |
| 打卡持久化 | `localStorage`，key `checkinShops` |
| 登录态持久化 | `localStorage`，key `loggedIn` |
| 未登录拦截 | `requireLogin()` 前置判断，引导去 `login.html` |
| 埋点占位 | 每页统一定义 `function track(event, data) { console.log('[track]', event, data); }` |
| 防 XSS | 用户输入渲染前过 `escapeHtml()` |
| 内容不足回退 | 首页内容 < 3 条时回捞旧内容补位。**仅在未筛选时生效**，筛选态禁用 |
| 筛选条件持久化 | `localStorage`，key `clientFilter`，存 `{ tiers, tastes }`；两维全空则删 key |
| 筛选状态条 | 首页顶部，仅筛选生效时显示；右侧「清除」一键恢复，⚙ 变红 |
| 筛选口径统一 | 筛选页与首页**共用 `MOCK.buildFeed`**，避免两处条数对不上 |
| 返回缓存刷新 | 监听 `pageshow`（`e.persisted`）重读条件重绘 —— 否则改完筛选按返回键首页不变 |
| 价格档变更联动 | `config.html` 保存时遍历 `MOCK.dishes` 重算 `priceTierId` |

**随心看 Tab**：随机排序 + **排除已浏览**。
**附近 Tab**：置顶 > 权重 > 距离 > 时间衰减。
两个 Tab **都受筛选影响** —— 筛选在出流前先过滤候选池。

## 10. 后端工程（S4 已交付）

**位置**：`server/`，Spring Boot 3.2.5 + Java 17 + JPA + Lombok。
默认 **H2 内存库**，`mvn spring-boot:run` 开箱即跑；用 `-Dspring-boot.run.profiles=mysql` 切 MySQL。

**包结构**：

├── repository/ 6 个 JpaRepository

**6 张表**：`shop` `dish` `comment` `app_user` `report` `platform_config`（DDL 见 `server/src/main/resources/db/schema.sql`）
