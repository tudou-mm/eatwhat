# 第一部分 · 商家端（merchant/）

## M1. 登录 / 注册

| 区块 | 内容 |
|---|---|
| 品牌区 | Logo + "商家入驻" |
| 表单 | 手机号、验证码 / 密码 |
| 底部 | 「还没有账号？立即注册」 |

**注册流程**：手机号 → 验证码 → 设置密码 → **提交店铺资质**

**资质表单字段**：
- 店铺名称（必填）
- 门头图（必填，1 张）
- 店铺地址（必填，**地图选点**，自动带经纬度）
- 联系电话（必填）
- 营业时间（必填）
- 菜系分类（必填，下拉）
- 店铺简介（选填）
- 店铺照片（选填，多张）

### 交互与校验规则

| 位置 | 规则 |
|---|---|
| 类型选择 | 单选，**选定后锁定**，页面提示不可更改 |
| 图片上传 | 最少 1 张，最多 9 张，支持拖拽排序，第 1 张自动成封面 |
| 视频上传 | 前端校验时长 ≤15s、大小 ≤20MB，超限直接拦截并提示 |
| 视频封面 | 选填；不上传则列表取视频首帧 |
| 菜名 | 必填，≤20 字 |
| 店名 | 必填，自动带入当前店铺名，可改 |
| 简介 | 选填，≤100 字，实时计数 |
| 价格 | 选填，数字；填了则**实时显示归入的档位** |
| 提交按钮 | 未满足必填时置灰；点击后二次确认（"每天只能发一条，确认发布？"） |
| 冷却拦截 | 进入页面时若在冷却期，**整页替换为倒计时提示**，不给进 |

│      │               │      │

│  ┌「实拍认证」┐              │  ← 真实性标签

│                             │
│  ┌─────────────────────────┐│
│  │ 🏪 店铺卡片（可展开）      ││
│  │  门头图 + 地址 + 营业时间  ││

│  │ ❤️ │ │ ⭐ │ │ 💬 │ │ ⋯ ││  ← 右侧操作栏
│  │ 32 │ │ 15 │ │ 8  │ │更多││
│  └────┘ └────┘ └────┘ └────┘│

### 右侧操作栏

| 图标 | 功能 | 未登录行为 |
|---|---|---|
| ❤️ | 点赞 | 弹出登录 |
| ⭐ | 收藏 | 弹出登录 |
| 💬 | 评论 → 打开评论面板 | 弹出登录 |
| ⋯ 更多 | 见下 | — |

### 「更多」三级菜单

```
⋯ 更多
  ├── 分享          → 复制链接 / 生成海报
  ├── 导航到店       → 唤起地图 App 路线
  ├── 电话          → 拨打店铺电话
  └── 去美团看看     → 跳转第三方平台
```

### Tab 切换

| Tab | 算法 | 说明 |
|---|---|---|
| 附近 | 平台置顶 > 权重 > 距离 > 时间衰减 | 需定位授权，未授权则手动选城市 |
| 随心看 | 随机（排除已浏览） | 记录浏览历史到本地 |

```
┌────────────────────────────┐
│  ← 筛选              [重置] │
├────────────────────────────┤
│  价格档（多选）              │
│  [中等] [高等] [超高级]      │
│                            │
│  口味（多选）                │
│  [麻辣] [清淡] [酸甜]        │
│  [烧烤] [火锅] [日料] ...    │
│                            │
│  距离                        │
│  （本期不做范围限制）          │
├────────────────────────────┤
│         [ 查看结果 ]         │
└────────────────────────────┘
```

**规则**：价格档 + 口味 = 多选，多选之间是 **AND（同时满足）** 还是 **OR（任一满足）**？
→ **设计取 OR**（选"麻辣"，则所有麻辣菜品都进来），更符合"我想吃点辣的"这种心理。
