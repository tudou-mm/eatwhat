## 二、核心流程图

### 2.1 商家发布菜品（主流程）

```
[商家打开商家端]
      ↓
[是否已登录？] ──否──→ [登录/注册] → [提交资质] → [等待平台审核]
      ↓是                                              ↓
[是否已通过审核？] ──否──→ [显示审核状态页]        [平台审核]
      ↓是                                              ↓
[工作台：显示上次发布时间]                        [通过 → 可发布]
      ↓
[点击"发布新菜品"]
      ↓
[距上次发布 ≥ 24h？] ──否──→ [提示：还剩 X 小时解锁]──┐
      ↓是                                              │
[选择类型：图文 / 视频]                                │
      ↓                                                │
[上传媒体] ← 校验：图1-9张 / 视频≤15s≤20MB             │
      ↓                                                │
[填写必填：菜名、店名]                                 │
[选填：简介≤100字、价格、视频封面]                      │
      ↓                                                │
[填写价格 → 系统自动归入价格档]                         │
      ↓                                                │
[提交]                                                 │
      ↓                                                │
[发布成功] → [记录发布时刻] ← ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┘
      ↓
[内容上首页 + 进店铺菜单]
      ↓
[商家可编辑文字/图片，不可改类型]
```

### 2.2 平台审核店铺（准入流程）

```
[商家提交资质]
      ↓
[进入平台端"商家审核"队列]
      ↓
[运营查看：店名/门头/地址/电话/资质]
      ↓
   ┌──┴──┐
[通过] [驳回]
   ↓      ↓
[店铺上线] [填写驳回原因 → 通知商家 → 商家可重新提交]
   ↓
[可在店铺管理中：编辑 / 封店]
```

### 2.3 平台配置推荐排名

```
[运营进入"推荐排名管理"]
      ↓
[选择地区] ← 排名按地区独立
      ↓
[展示该地区店铺列表（当前排序）]
      ↓
[操作方式]
   ├── 拖拽调整顺序
   ├── 设为置顶（置顶优先于一切）
   └── 设置权重（数值越高越靠前）
      ↓
[保存]
      ↓
[客户端首页生效]
排序优先级：置顶 > 权重 > 距离 > 时间衰减
```

### 2.4 用户端信息流消费

```
[用户打开客户端]
      ↓
[是否授权定位？] ──否──→ [猜城市 / 手动选城市]
      ↓是                       ↓
      └──────────┬──────────────┘
                 ↓
        [首页：双 Tab]
                 ↓
        ┌────────┴────────┐
   Tab-A「附近」      Tab-B「随心看」
   距离+时间衰减       随机(排除已浏览)
        │                 │
        └────────┬────────┘
                 ↓
      [全屏竖向滑动卡片]
      媒体 + 菜名 + 简介 + 店名 + 价格档
                 ↓
      [卡片操作区]
      ├── 点赞 ─→ 未登录? → 弹登录
      ├── 收藏 ─→ 未登录? → 弹登录
      ├── 评论 ─→ 未登录? → 弹登录
      └── 更多 ─┐
                ├── 分享
                ├── 导航到店
                ├── 电话
                └── 跳转美团/大众点评
                 ↓
      [点击店名/卡片 → 店铺详情页]
                 ↓
      [店铺详情：店铺信息 + 全部菜品]
```

### 2.5 内容生命周期

```
[商家发布]  T=0
      ↓
[首页展示]  T=0 ~ T+24h   权重满值
      ↓
[T+24h]    权重衰减到底，但【不删除】
      ↓
   ┌──┴──┐
[商家发新菜]  [一直没发]
   ↓              ↓
[旧菜被顶替]   [仍挂首页底部]
   ↓              ↓
[店铺页永久保留]  [店铺页永久保留]
```

### 2.6 违规处理（平台端）

```
[来源]
 ├── 运营主动巡查
 └── 用户举报（含恶意刷差评举报）
      ↓
[平台端核实]
      ↓
   ┌──┴──┬────────┬─────────┐
[内容下架] [商家禁言] [封店] [驳回举报]
   ↓        ↓         ↓        ↓
[菜从首页撤下] [禁发/禁评] [禁止登录] [不做处理]
```

## 三、状态机

### 3.1 店铺状态

```
待审核 → 已通过 → 正常运营
        ↓          ├── 禁言中
      驳回         └── 已封禁
        ↓
     （可重新提交）
```

### 3.2 菜品状态

```
已发布 → 正常展示
       ├── 已编辑（内容更新）
       └── 已下架（违规）
```

### 3.3 商家发布态

```
可发布 ──(发完)──→ 冷却中(24h 倒计时) ──(倒计时结束)──→ 可发布
```
